# 摘录库（excerpts）

把刷手机时看到的好段落与观点（文字或图片）捕获入库的素材体系。与「会话知识沉淀（knowledge-base）」是姊妹体系：那边收已验证的技术结论，这边收未加工的原始素材，互不写入。

## Language

**摘录 (excerpt)**:
刷手机时捕获的一段好内容的原始记录，文字或图片；来源是公开内容或他人观点，未经验证，不承担知识库条目的约束。
_Avoid_: 条目（特指知识库条目）、笔记、收藏

**捕获 (capture)**:
用户在手机上把好内容送进系统的动作：复制文字或截图后经通用出口发出；不针对任何特定 App 做集成。
_Avoid_: 收集（泛指整条链路）、保存

**原文保真**:
摘录必须完整保留原始文字或原图；转写、分类、摘要只是附加层，任何环节不得改写或丢弃原文。
_Avoid_: 精炼、整理、消化

**收集端点 (capture endpoint)**:
手机侧推送摘录的唯一入库入口；此外没有第二条通道。
_Avoid_: 服务器、接口、机器人（那只是它的一种实现形态）

**待确认 (staged)**:
摘录被自动分类后的暂存状态；未经人工确认不得进入正式分类目录。
_Avoid_: 待发布、草稿

**确认 (confirm)**:
人工对待确认摘录的裁决：按原分类放行 / 改类放行 / 删除；是摘录进入正式目录的唯一途径。
_Avoid_: 审核（过重）、提交

**摘录库 (excerpt library)**:
全部摘录的集合，含原始素材与正式分类目录；与知识库平行，互不写入。
_Avoid_: 素材库、第二知识库
