# 注释校验默认不自动写盘修复

`check_annotations.py` 对行尾标点等可机械修复项**默认只报错不改文件**，`--fix` 必须显式开启；且补号容易把句中折行切成病句，开启后仍应优先按语义断点人工重排。

原因：注释是自然语言，自动补号是语法级修复而非语义级——真实事故（补写注释时吞掉代码字符、分号丢失）证明写盘修复的风险高于重跑成本。校验器的职责是把"哪里不合格"说清楚，修复权留给人/agent 按语义断点处理。

被否的替代方案：校验通过后自动 `--fix` 再复核——两步看似省事，实际把"语义断点在哪"的判断藏进了脚本，错修会被后续 AI 当事实吸收（注释层没有编译期检查兜底）。
