# 十六标签体系封版

标注注释的【标签】集合固定为 16 个，不再扩充；"伤疤""边界"等是**行类型/内容概念**，不是标签，落笔时映射到既有标签（伤疤→【注意事项】，边界→【关键细节】）。

原因：标签体系同时承担三件事——注释形态规范、`grep "【"` 的检索锚点、校验脚本的合法性判定。每扩一个标签，三处都要跟随，且概念词与标签的边界会持续模糊（2026-09 输入系统标注实战中，agent 因正文用"伤疤类行"当术语而两次误用【伤疤】标签被脚本拦截，即为本决策的直接动因）。概念的丰富度放在定义与映射里，不放在标签数量里。

被否的替代方案：扩成第 17 个标签【伤疤】——检索锚点碎片化，且"伤疤"是识别技巧而非读者疑问维度，与 16 标签的阅读链定位（是什么→做什么→为什么→…）不匹配。
