## 问答式（仅【为什么】标签）

问题以问号结尾（可紧跟标签，或独立成行），答案另起一行；答案内分点用 1. 2. 3.、每点尽量一行写完。适合"为什么这样设计 / 为什么不这样做"；陈述式标签不硬凑问句。

## 【设计思想】启示分点的必备要素（v1.22 新增）

"对 SDK 设计的启示是…"分点（见上方【设计思想】示例第 5 点）每条必须回答三件事：

1. **做法**：可复用的手法是什么（一句话讲清结构，不空喊模式名）；
2. **适用条件**：什么信号/环境下用它（"初始化顺序解不开依赖环时""管理器要持有别人的对象时"）；
3. **反例代价**：不适用或选错会怎样（一句点到即可）。

三件缺一即为口号式启示，返工。分析中每遇到新类/新角色都过一遍该思考（产出分级见 SKILL.md §3.3：简单角色类头一句话即可，不落块）。

## 使用示例块（两面讲解的代码部分，v1.22 新增）

"应用侧怎么用"的讲解，示例代码直接贴在行注释内，缩进比引导行深一级；示例前必有一句场景：

```java
// 怎么用（应用侧接入三步）：
//   1. build.gradle 加 annotationProcessor 'com.github.bumptech.glide:compiler'。
//   2. 写模块类。场景示例——把全局内存缓存上限调成 20MB（低内存设备的常见诉求）：
//        @GlideModule
//        public class MyAppGlideModule extends AppGlideModule {
//          @Override
//          public void applyOptions(Context context, GlideBuilder builder) {
//            builder.setMemoryCache(new LruResourceCache(20 * 1024 * 1024));
//          }
//        }
//   3. Rebuild 即生效。
```

规则：

- 示例 = 最小可运行骨架（5-10 行），删到不能再删仍能说明用法；XML/gradle 片段同理（2-4 行）。
- 示例前必有一句**场景**（什么情况下用它），示例后可补一句"不用/不接会怎样"。
- 示例中的类名/方法名/参数必须回查当前源码；本仓未检出的依赖类标注示意 `[inferred]`。
- 示例行是代码不是散文——无 CJK 的示例行不参与行尾标点检查（校验脚本口径）。
- 同一示例只贴一次（概念本体文件的类头处），流程方法处给角色定位与回指，不重复贴。

## 换行与排版规范（所有换行规则集中于此）

**何时分行**——五种触发，缺一不可：

- **列表化优先**：可枚举的内容（并列/步骤/条件/分支/要点）一律转列表——**有序用 1. 2. 3.、无序用 - 开头**，每项一行（缩进 2）；分号串列（A；B；C 挤一行）是典型反模式，分点内部的次级并列用顿号/逗号表达，一行内不出现分号并列；
- **行尾标点**：每行注释必须以标点结尾（陈述用句号、问句用问号、引出列表用冒号），不允许无标点换行——续行落笔时就以标点收尾，不靠脚本补（自动补号会把句中折行切成病句）；
- **链路箭头化**：调用链（【核心流程】【调用关系】）用箭头连接，节点用代码符号（类名/方法名），每行一个链段；必要说明放括注 `(原因)`，中文叙述只用于箭头表达不了的设计动机，不写"先…再…然后…"的叙事句；链路 ASCII 总论图的多行画法见 §3.1 链路总览前置；
- **段间空行**：大块注释按语义分段，段间用空注释行 `//` 隔断（文件头总论可用 `// ───` 分割线，同一文件内二选一保持一致）；
- **行宽自适应**：上限 = 所在文件 HEAD 既有行的最大显示列（中文按 2 列计），下限 130，校验脚本自动探测，`--max-width` 可覆盖——注释不超出所在文件自身的宽度包络，换库无需改规范。主动分行（分点/箭头/分段）按语义断点自然结束，被动折行（内容超长）时尽量填满至接近上限再在合法断点换行，避免同一块内行宽忽长忽短。（历史：v1.20 及以前固定 130——上游注释宽度各库不一，改为与所在文件既有行宽统一。）

**怎么折行**——四种统一形态：

- **断点**：在标点/词组边界断，不劈词、不劈括号（括注跨行最易错，括注整个挪到下一行行首或在本行内闭合）；
- **统一缩进**：折行续行、列表项、括注、箭头接续一律缩进 2（纯 ASCII，跨字体稳定）；分支/子项再 +2；**禁止悬挂对齐中文标签/全角字符**（跨字体必错位）；
- **箭头接续**：链路折行新行以 `→` 开头；禁止行尾悬空箭头（`A → B →` 结尾）与 `/` 续行；
- **一行一义**：每行表达一个完整语义单元（一个并列项/一个链段/一句因果），竖排行首即可读出结构。
