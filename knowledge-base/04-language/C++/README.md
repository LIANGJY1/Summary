# C++ 学习资料

> 本目录按基础概念、构建工具、系统接口、类型和内存主题组织 C++ 学习笔记。文档结构和题目编号遵守 [WRITING-GUIDE.md](../../WRITING-GUIDE.md)。

1. `01-language-fundamentals.md`：词法与对象基础、编程范式、头文件与命名空间、程序模型、入口函数和基础 I/O（28 题）。
2. `02-build-and-link.md`：预处理、编译链接、头文件机制与保护宏、工具链选项和产物检查（11 题）。
3. `03-posix-apis.md`：POSIX 接口与最小 `/init` 示例（6 题）。
4. `04-functions-and-types.md`：函数、基本类型、初始化、字符、数值与转换（23 题）。
5. `05-arrays-and-strings.md`：数组、C 风格字符串、输入流和 `std::string`（15 题）。
6. `06-user-defined-types.md`：结构体、共同体和枚举（11 题）。
7. `07-pointers-and-memory.md`：指针语义、数组关系、存储期、动态分配与资源管理（17 题）。

`cpp_practice_project/` 保存练习代码，不属于问答文档。
