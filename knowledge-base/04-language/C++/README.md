# C++ 学习资料

> 本目录按基础概念、构建工具、系统接口、类型和内存主题组织 C++ 学习笔记。题目编号在各文档内从 Q1 连续编排。

1. `01-language-fundamentals.md`：编程范式、可移植性、头文件、命名空间、入口函数、I/O 与对象基础（24 题）。
2. `02-build-and-link.md`：预处理、编译链接、头文件机制与保护宏、工具链选项和产物检查（10 题）。
3. `03-posix-apis.md`：POSIX 接口与最小 `/init` 示例（5 题）。
4. `04-functions-and-types.md`：函数、基本类型、初始化、字符、数值与转换（22 题）。
5. `05-arrays-and-strings.md`：数组、C 风格字符串、输入流和 `std::string`（13 题）。
6. `06-user-defined-types.md`：结构体、共同体和枚举（10 题）。
7. `07-pointers-and-memory.md`：指针、数组关系、存储期、动态分配与容器（22 题）。

`cpp_practice_project/` 保存练习代码，不属于问答文档。
