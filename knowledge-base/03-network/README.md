# 通用网络协议学习资料

本目录收录平台无关的网络协议，共 2 篇资料、18 道题。Android 与车载网络的实现、策略和诊断见 [Android 网络与车载网络](../01-android/09-network/README.md)，通用套接字接口见 [进程与通信](../02-os/03-进程与通信/README.md)。文档结构和编号遵守 [WRITING-GUIDE.md](../WRITING-GUIDE.md)。

## 册

1. [网络基础](01-网络基础.md)（14 题）。分层模型、DNS 递归、TLS 握手、TCP 状态机、IP 分片、NAT 与 conntrack、网络分类、RFC、性能指标和 MAC 地址。
2. [HTTP 缓存与传输](02-HTTP.md)（4 题）。缓存新鲜度和条件请求、HTTP/2 流复用与流量控制、HTTP/3 与 QUIC 的丢包隔离、迁移和 0-RTT。
