# 知识库术语

知识库收录脱离单次任务后仍可复用、能够帮助理解机制或解决实际问题的知识。原始摘录、任务流水账和交接内容不属于知识。

## 核心术语

**知识：**换一个项目仍然成立，并且能用于解释机制、作出选择或排查问题的结论。

**主题册：**围绕一个稳定主题组织的问答文档。主题边界由所在目录的 README 和文档开头说明。

**问题：**以 `Qn` 标识的最小复习单元。每题聚焦一个核心问题，答案必须说明成立条件、关键机制和会改变结论的边界。

**路由：**按知识内核选择唯一主题的过程。先查 [ROUTING.md](./ROUTING.md)，再检查候选目录和文档的边界。

**证据：**支持结论的源码、官方资料、设备输出、实验结果或项目材料。版本敏感结论应能定位到对应版本和依据。推断必须明确标记，不能写成已验证事实。

**沉淀：**把当前任务中可迁移的结论写入对应主题册。单次操作过程留在项目文档或问题复盘中。

## 内容边界

1. 技术机制按主题进入 Android、操作系统、网络、语言、设计、测试或开发工具目录。
2. 跨项目的非技术判断规则进入 `08-exp/`。
3. 特定项目事实进入项目档案。单次问题经过进入仓库根目录 `issue/`。
4. 可重复执行的工作流程写成 skill，不作为知识题目保存。
