# 会话知识沉淀（knowledge-base）

把跨会话仍可复用的结论固化为可检索知识资产的体系。知识库固定位于 `Summary/knowledge-base/`，按知识主题路由；写入者不改变知识的主题归属。

## 与 career 的关系

`Summary/knowledge-base/career/` 是 Android 车机求职和真实项目复盘的应用层入口：它可以引用本库的通用知识，但不复制正文。求职过程中形成、且换项目仍成立的结论，按 `ROUTING.md` 沉淀回本库；只对当前岗位、简历或某个项目有效的内容留在 `career/`。

## Language

**知识库 (knowledge-base)**:
Summary 内统一的知识与学习内容入口：既包含按路由沉淀的可迁移知识条目，也包含 Android（`01-android/`）、软件测试（`06-testing/`）、语言（`04-language/`）、项目经验（`08-exp/`）、操作系统与文件系统（`02-os/`）、设计模式（`05-design/`）、通用网络（`03-network/`）及真实项目分析（`career/`）等人读学习资料目录。
_Avoid_: 把项目资料、原始摘录或交接记录混入知识库

**学习资料目录**:
`knowledge-base/` 下以目录组织的长篇学习材料，服务于连续阅读和系统学习；它们不直接参与 `knowledge-entry` 的大类路由，但其中形成的可迁移结论仍按 `ROUTING.md` 写入条目。
_Avoid_: 把学习资料目录当作新的知识条目大类

**大类**:
知识库下收纳同一主题知识的文档。其文件命名、标题、引言、目录与条目格式遵守 [`WRITING-GUIDE.md`](./WRITING-GUIDE.md)。
_Avoid_: 分类、知识文档、目录（与文件系统目录混淆）

**profile**:
知识落盘的内容形态。`knowledge-entry` 是条目型文档；`language-note` 是 `04-language/` 下的学习材料。各形态的结构和写作要求统一见 [`WRITING-GUIDE.md`](./WRITING-GUIDE.md)，主题边界按路由文档判断。
_Avoid_: 统一模板、文章类型

**条目**:
可独立检索和使用的一条知识。条目的标题、组织方式及归并规则遵守 [`WRITING-GUIDE.md`](./WRITING-GUIDE.md)。
_Avoid_: 知识点、段落

**边界**:
每个大类文档顶部的"收什么 / 不收什么 / 与兄弟文档如何分工"声明；新建大类必须先立边界。
_Avoid_: 说明、前言

**路由**:
沉淀前确定知识去哪个大类的动作：先查根目录 `ROUTING.md`（主判据链 + 路由表）定候选，准入以目标大类头部「边界」为准；新立大类后必须回填路由表。
_Avoid_: 分流（旧称）、索引、归类

**沉淀**:
把当前会话中非显而易见、脱离本会话语境仍成立的结论写入知识库的行为；流水账与过程记录不属于沉淀。
_Avoid_: 总结（泛指）、归档

**复习者测试**:
对 `knowledge-entry` 的准入问题：六个月后遇到什么问题会翻到它，翻到后能否直接使用。说不出具体场景或动作的候选不收；该测试不适用于 `language-note`。
_Avoid_: 阅读量、学习记录

**证据等级**:
对论断来源的标记：`observed`（直接观察）、`verified`（独立交叉确认）、`inferred`（有依据的未验证推断）、`external`（已与本地事实核对的外部资料）。
_Avoid_: 可信度百分比

证据等级用于标记论断来源；正文是否及如何注明来源遵守 [`WRITING-GUIDE.md`](./WRITING-GUIDE.md)。

**维护者**:
对大类的责任与复核标记，不是分类轴，也不是新建近义大类的理由。路由按知识主题决定唯一落点；所有写入者共用同一结构契约和校验器。
_Avoid_: 文件所有者、唯一写手

**修订注记**:
对同一结论的补充或适用条件收窄所做的语义更新；结论反转改用 supersedes。修订写法遵守 [`WRITING-GUIDE.md`](./WRITING-GUIDE.md)。
_Avoid_: 日期戳、替代关系

**supersedes**:
`knowledge-entry` 条目间表示结论替代关系的语义标记；`language-note` 不使用此条目关系。写法及修订方式统一遵守 [`WRITING-GUIDE.md`](./WRITING-GUIDE.md)。
_Avoid_: 作废、删除

旧条目保留用于追溯，不表示两套结论同时适用。

**知识**:
可迁移的结论：换一个项目仍然成立，且能通过复习者测试（六个月后遇到什么问题会翻到它、翻到后能直接用）。
_Avoid_: 经验（泛指）、结论

**工作记录**:
只对本次任务/项目有意义的操作结论（怎么收编、怎么分工、改了什么）；不属于沉淀，归宿是项目文档或交接。
_Avoid_: 知识、踩坑总结

**技能沉淀**:
可复用的工作流程固化为 `SKILL.md`（由 session-to-skill 负责），不进知识库。
_Avoid_: 与"沉淀"混用

**交接**:
给下一个 agent 续做用的上下文文档（由 handoff 负责），不进知识库。
_Avoid_: 与"沉淀"混用
