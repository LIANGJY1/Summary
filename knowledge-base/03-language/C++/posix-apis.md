# C++ 中的 POSIX 系统接口

> 本文说明 POSIX 接口是什么、C++ 如何包含并链接 POSIX 函数，以及 `pause()` 在最小 `/init` 示例中的阻塞等待。

**Q1: [learning] 什么是 POSIX 函数，C++ 程序什么时候应该使用？**

POSIX 函数是 POSIX（Portable Operating System Interface，可移植操作系统接口）标准定义的操作系统接口，不属于 ISO C++ 标准库；C++ 程序可以通过相应头文件调用目标平台提供的实现。

1. **需要操作系统能力时：**例如操作文件描述符、进程或信号，并且目标平台提供相应 POSIX 接口时，可以使用。
2. **需要跨平台时：**如果程序还要支持不提供 POSIX 的平台，优先使用 C++ 标准库，或把 POSIX 调用封装在平台适配层中。能包含 `<unistd.h>` 不代表所有 C++ 环境都支持它。

**Q2: [learning] C++ 调用 POSIX 函数时，应该包含哪个头文件、链接什么库？**

POSIX 不是一个统一的 `libposix` 库。调用 POSIX 函数要分别处理声明和实现：

1. **包含头文件：**按函数文档包含声明它的头文件；例如 `pause()` 使用 `#include <unistd.h>`。
2. **链接实现：**Linux 上的 `pause()` 由系统 C 库 `libc` 提供，常规 `g++` 链接流程会自动链接它，因此不需要额外写 `-lposix` 或 `-lc`。
3. **核对平台要求：**其他 POSIX 函数可能需要额外库或编译选项，目标平台也必须提供该接口；按目标平台文档配置。

**Q3: [done] 最小 `/init` 示例中的 `pause()` 有什么作用？**

`pause()` 是 `<unistd.h>` 提供的 POSIX 函数，会让当前进程阻塞等待信号，因此不会像空循环那样持续占用 CPU。收到由已安装信号处理函数处理的信号后，处理函数返回，`pause()` 才返回 `-1` 并设置 `errno` 为 `EINTR`；外层 `while (true)` 随后再次等待。

示例没有注册信号处理函数，所以它只是让最小 `/init` 暂时阻塞保活，不是能响应关机或管理子进程的完整 PID 1。Linux 对 PID 1 接收信号有特殊限制，不能把 `pause()` 理解成收到任意信号都会返回。
