# Java 注解

> Java 注解与元注解学习资料。Q 序列即结构。

**Q1: Java 注解声明了什么？注解会自动改变程序行为吗？**

注解为声明附加结构化元数据，但单独声明注解不会自动改变程序行为。编译器、注解处理器、运行时框架或工具必须读取并解释这些元数据，行为才会随之变化。

**Q2: Retention、Target 和 Inherited 分别控制什么？**

`@Retention` 指定注解保留到源码、class 文件还是运行时；`@Target` 限制注解可放置的位置；`@Inherited` 影响类级注解能否沿父类查询继承，不会让方法或接口注解自动继承。

应按消费者选择保留策略：只供编译期使用的注解通常不必保留到运行时；反射读取需要运行时保留。

**Q3: 注解处理器与运行时反射读取注解有什么区别？**

注解处理器在编译期检查源代码并可生成代码或资源；运行时反射读取依赖 class 文件中保留相应注解并在程序运行时扫描。编译期处理可较早报告错误，运行时读取则可根据实际类型动态工作。
