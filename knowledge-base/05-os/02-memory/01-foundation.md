# 内存基础

> 学习资料。先分清持久化存储与运行内存，再理解 Android 如何在两者之间装入和保存数据。

**Q1: 闪存和 RAM 有什么区别，Android 分别用它们做什么？**

闪存负责断电后仍要保留的数据，RAM 负责设备运行时正在使用的数据。Android 把系统镜像、应用文件和用户文件保存在闪存中，运行时再把需要的代码和数据装入 RAM。

1. **闪存：长期保存**。手机内置持久化存储通常以 NAND 闪存为介质，并通过 UFS 或 eMMC 存储设备供系统访问。它断电后仍能保存数据，操作系统通过文件系统读写分区中的文件。系统文件、已安装 APK、照片和下载内容都属于这类持久化数据。“闪存”之名来自发明团队把整块擦除过程比作相机闪光，指擦除动作很快。

2. **RAM：运行时工作区**。手机的主内存通常是 DRAM，设备供电时才能保留内容。内核、进程正在使用的代码和数据，以及文件缓存都可能占用 RAM。RAM 的随机访问延迟通常远低于闪存，适合 CPU 运行时频繁访问。断电后其中的数据会丢失。

3. **应用运行时两者如何配合：**

    1. APK 和应用数据文件保存在闪存中。
    2. 启动应用时，内核按需把程序代码和数据页读入 RAM。文件不一定会一次性全部载入。
    3. 应用修改 RAM 中的数据后，只有通过文件写入等持久化操作保存，数据才会留在闪存中。进程退出后，系统可以回收它占用的 RAM，但不会因此删除 APK 或用户文件。

4. **不要把两者当成同一种容量：**两者容量不足时影响不同：

    1. 闪存不足会限制系统、应用和用户文件的长期保存，安装、下载或存储操作可能失败。
    2. RAM 不足会限制运行时可同时保留的活跃数据，系统需要回收缓存或结束进程。
