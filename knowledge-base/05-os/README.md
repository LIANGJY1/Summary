# 操作系统学习资料

> 收录 13 篇、48 道通用操作系统题，按运行机制、进程调度、内存、文件系统与虚拟化组织。Android 专属实现归 `../01-android/`；Java/JVM 语言与运行时知识按知识路由归入相应主题。

## 推荐阅读顺序

1. 先读操作系统职责、进程状态与地址空间基础。
2. 再读内存管理和文件系统机制。
3. 最后读虚拟化边界，并用各专题的实践问题检验概念。

1. [操作系统基础与运行机制](01-os-fundamentals.md)（6 题）— 操作系统职责、并发与共享、用户态/内核态、系统调用及内核架构。
2. [进程与处理机调度](02-processes-and-scheduling.md)（8 题）— 进程映像、状态转换、线程、调度层次与策略。

## 内存管理

1. [内存基础](02-memory/01-foundation.md)（2 题）— 闪存与 RAM 的区别、Android 中的用途及 Flash 命名来源。
2. [内存管理](03-memory-management.md)（10 题）— 连续与离散分配、分页分段、虚拟内存、进程映像和内存映射。
