# 操作系统学习资料

4. [内存管理](03-内存管理.md) — 连续与离散分配、分页分段、虚拟内存、进程映像和内存映射。
5. [虚拟机与虚拟化](04-虚拟机与虚拟化.md) — 第一类与第二类虚拟机监控程序的资源边界和取舍。
