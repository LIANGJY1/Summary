**Q1: VFS 怎样让应用用统一接口访问不同文件系统？**

虚拟文件系统在具体文件系统之上提供通用操作入口，并把操作分派给对应文件系统实现。应用按路径和通用文件操作访问对象，不必为每种文件系统编写一套调用接口。

**Q2: vnode 和 inode 是同一个对象吗？**

不是。vnode 是 VFS 层的内存对象，用统一形式表示文件并关联具体文件系统操作；inode 是具体文件系统使用的元数据对象，通常有持久化表示并在访问时进入内存。两者关系由内核实现维护，不能简单说成每次打开都把 inode 完整复制成 vnode。

**Q3: 文件系统挂载后，路径查找发生了什么变化？**

挂载把一个文件系统的根接到现有目录树中的挂载点；路径遍历到该挂载点时，后续查找转入被挂载文件系统。挂载通常需要注册文件系统类型、准备超级块或根对象并建立挂载关系，具体步骤随操作系统与文件系统实现而异。
