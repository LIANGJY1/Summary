# Android 性能优化

本目录沿着性能问题的分析路径组织：先掌握共用方法，再分别学习应用、Android 系统和底层实现；性能工具作为贯穿各层的独立入口。知识内容遵守 [WRITING-GUIDE.md](../../WRITING-GUIDE.md)。

## 分类边界

1. **基础：**性能指标、测量实验与分析方法，为各层优化提供共同的判断框架。
2. **应用：**应用代码、配置、公开 API 使用和运行机制，按启动、渲染、内存、网络、CPU、图片、能效与稳定性等优化对象分类。
3. **系统：**Framework、system_server、系统服务与系统 Native，按系统子系统分类。
4. **底层：**HAL、内核、驱动及硬件执行路径，按底层子系统分类。
5. **工具：**按采集与追踪、性能剖析、基准与交付、能耗测量、平台诊断、线上监控与 APM 等能力分组；每个工具保留独立条目，并由工具名索引查找。

跨层题目按主要解释对象放入对应层级，并通过链接连接相关层。工具条目解释采集、输出和使用边界；性能主题解释根因机制和优化判断。

## 推荐阅读路径

1. 从[基础](./00-基础/README.md)学习问题定义、测量条件、基线和证据边界。
2. 从[应用](./01-应用/README.md)按用户可见的问题定位优化对象。
3. 证据指向平台行为时，继续阅读[系统](./02-系统/README.md)和[底层](./03-底层/README.md)对应子系统。
4. 在需要采集或验证时，从[工具](./04-工具/README.md)按能力或工具名称进入。
