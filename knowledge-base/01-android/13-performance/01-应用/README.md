# 应用性能优化

本目录收录应用自身代码、API、配置和运行机制相关的性能题目。Framework、系统服务、内核与驱动实现，以及独立工具的完整使用方法留在对应主题；应用题在需要时链接这些层的机制边界。

## 推荐学习顺序

1. **启动与交付：**理解启动关键路径、初始化依赖和应用交付，建立从安装到首屏的成本模型。
2. **用户体验：**学习界面渲染、滚动与交互反馈，分清应用工作量和显示链路等待。
3. **资源热点：**按内存、网络请求、CPU 并发和图片加载深入，识别分配、计算、等待、传输与解码各自的代价。
4. **后台能效：**理解任务调度、定位/传感器/蓝牙/音视频后台行为及省电约束。
5. **稳定性：**学习 ANR 风险、崩溃处理、生命周期竞态和状态收敛，形成运行期可靠性闭环。
