# Android 性能优化

本目录按“基础 → 应用 → 系统 → 底层”逐层组织性能知识，并把工具作为平级入口。应用和系统文章按优化方向分类；案例与经验写在对应方向中，不单设经验目录。知识内容遵守 [WRITING-GUIDE.md](../../WRITING-GUIDE.md)。

## 分类边界

1. **基础：**归纳各类性能问题共用的指标、实验与分析方法。Android、操作系统、网络等详细前置知识仍在知识库原主题目录，本目录不重复讲解。
2. **应用：**优化对象是 App 的代码、配置、公开 API 使用和应用运行机制，按启动与交付、渲染、内存、CPU、网络、能效、稳定性等方向查找。
3. **系统：**优化对象是 Framework、system_server、系统服务和系统 Native 组件，按其影响的性能方向查找。
4. **底层：**单独收录 HAL、内核和驱动机制，避免与 Framework 或 App 混为一个范围。
5. **工具：**每种主要工具各自成组，集中讲用途、采集条件、结果解释和适用边界。性能问题文章只引用需要的工具内容。

跨层问题按题目主要解释的对象拆分，相关层之间用链接衔接。涉及多个优化方向时，按主要瓶颈归档，其他方向提供交叉入口。

## 推荐学习顺序

1. 先读[基础](./00-基础/README.md)，学会定义问题、固定测量条件、建立基线和限制结论强度。
2. 按用户看到的问题进入[应用](./01-应用/README.md)，从启动、渲染与响应开始，再按内存、CPU、网络、能效和稳定性深入。
3. 如果证据指向平台机制，进入[系统](./02-系统/README.md)，按 Framework、系统服务或系统 Native 的责任路径分析。
4. 如果责任路径继续进入硬件抽象或内核，进入[底层](./03-底层/README.md)，检查 HAL、调度、驱动、内存回收或温控等机制。
5. 在对应分析步骤中查阅[工具](./04-工具/README.md)，按工具组学习采集与分析流程；工具教程不替代根因判断。

## 分类入口

- [基础](./00-基础/README.md)：性能指标、测量实验和分析方法的简要归纳。
- [应用](./01-应用/README.md)：App 的性能优化方向与场景经验。
- [系统](./02-系统/README.md)：Framework、system_server、系统服务和系统 Native 的性能优化。
- [底层](./03-底层/README.md)：HAL、内核和驱动的性能机制与优化。
- [工具](./04-工具/README.md)：Perfetto、Profiler、基准测试、线上诊断等工具，各自成组。
