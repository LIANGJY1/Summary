# 基础

这里归纳性能分析和优化共用的判断框架。Android、操作系统、网络、内存与图形的详细机制仍在知识库各主题目录讲解，本目录只保留性能场景下需要的提要和导航。

## 推荐顺序

1. 阅读[性能分析与测量](./01-性能分析与测量.md)，明确场景、指标、实验和证据的关系。
2. 根据瓶颈进入[应用性能](../01-应用/README.md)、[系统性能](../02-系统/README.md)或[底层性能](../03-底层/README.md)。
3. 需要采集或验证时，从[性能工具](../04-工具/README.md)进入对应工具组。
