# Android 内存与存储

> 收录 7 册、183 道 Android 资源域题，分内存与存储两个域，域内按"机制 → 治理 → 应用实践"递进：内存域先讲进程内存口径、ART 堆与 GC、lmkd/Freezer 压力治理等机制层（01-02），再拆内存不足的稳定性失败路径（03），最后落地应用侧实践（04）；存储域先讲分区与挂载、存储栈等待层级等机制层（05-06），再落地应用侧 I/O 与存储实践（07）。机制均按 AAOS 13（Android 13）本地源码核对，不在本地树的组件按源材料转写并标注版本差异。

1. `01-内存管理.md`：Android 内存管理与压力治理：进程内存口径、内核页管理、ART 堆与 GC 调度、lmkd/缓存进程冻结器/MemoryLimiter 治理分层、16 KB Page Size（33 题）。
2. `02-回收与压缩.md`：回收压缩与专项内存：终结引用与 Cleaner 兜底边界、页规整与直接回收、ZRAM 压缩交换与写回预取、MTE 内存标签、共享内存与端侧推理内存预算（26 题）。
3. `03-应用内存稳定性.md`：稳定性治理：把"内存不足"拆成 Java 堆、Native、线程、地址空间与 FD 的独立失败路径，先分类再选工具，WebView renderer 的退出与恢复（25 题）。
4. `04-应用内存实践.md`：内存实践：堆预算与 GC 友好编码、泄漏治理、Native 与虚拟内存排查、Bitmap 优化、大内存与多进程策略、线上监控（32 题）。
5. `05-分区与挂载.md`：运行时分区与挂载：分区职责、动态分区与 `super` 容量关系、Virtual A/B 的 OTA 数据路径、system-as-root 根布局与挂载职责（6 题）。
6. `06-存储与IO.md`：存储与 I/O：沿"API → 文件系统 → 块层与调度 → 加密与映射 → FUSE → 器件"定位等待层级，SharedPreferences/DataStore 的 ANR 风险机制（23 题）。
7. `07-应用存储实践.md`：I/O 与存储实践：文件与键值存储、SQLite/Room 与序列化、缓存与离线优先、MediaStore 与 Photo Picker、网络连接容灾与 HTTP/2/3、gRPC 选型（38 题）。

**目录边界：**分区的镜像构建、打包与刷写归 `11-构建系统/04-系统镜像.md`；ART 的角色与演进总览归 `01-architecture/06-ART运行时.md`；ANR 机制层归 `13-performance/02-系统/04-稳定性与诊断/`；性能优化视角（对比实验、trace 归因）归 `13-performance/`，本目录回答资源本身的机制与治理。
