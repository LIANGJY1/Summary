# 串口通信

> 通用串口与设备连接基础。

**Q1: [done] UART 串口与 USB 有什么区别，适合什么场景？**

UART（Universal Asynchronous Receiver/Transmitter）是异步串行收发器。USB（Universal Serial Bus）也是串行通信，但使用主机管理的总线协议。两者的连接和使用方式不同。

1. **UART：**设备通常通过发送线和接收线直接交换字节，双方须匹配波特率和数据格式。它常用于芯片间通信、设备维护和早期启动日志。
2. **USB：**主机负责设备枚举，设备按 USB 协议与驱动交互，适合连接通用外设。USB 转串口适配器在 USB 与 UART 接口之间转换。
3. **连接条件：**UART 逻辑电平、RS-232 和 RS-485 的电气接口不同。连接前须核对电平、接线与通信参数。
