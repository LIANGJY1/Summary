# 存储空间管理

> 本册讨论文件系统的磁盘空闲空间管理。页分配和对象缓存归 [内存管理](../02-内存管理/02-内存管理.md)。

**Q1: [learning] 空闲表法、空闲盘块链和空闲盘区链如何记录可分配空间？**

三种方式分别以连续区间、单个盘块或区间链表记录空闲空间。选择影响查找、分配和回收时维护的信息量。

1. **空闲表：**记录各连续空闲区的起点与长度。分配时查找足够大的区间并更新表项，回收时可合并相邻区间。
2. **空闲盘块链：**每个空闲块记录下一块的位置。逐块分配直观，但寻找大量连续块可能需要遍历较多节点。
3. **空闲盘区链：**以连续空闲区为节点，每个节点记录区间和下一节点。批量分配连续空间时可减少节点操作，但仍需维护分裂和合并。

具体记录位置、缓存与崩溃恢复方式由文件系统实现决定。随着碎片增加，连续区间的数量也可能增长。

**Q2: [learning] 位视图如何把字号和位号换算成盘块号？**

若每个字有 `n` 位且字号、位号都从 0 开始，则盘块号为 `n × 字号 + 位号`。反向换算时，字号是盘块号除以 `n` 的商，位号是余数。计算前必须确认编号起点和位图中 0/1 对应空闲还是已分配。

**Q3: [learning] 成组链接法怎样避免空闲块清单过长？**

成组链接法把空闲块分组，每组记录一批块号并指向下一组。内存中的超级块保存当前组。当前组耗尽时先把下一组信息读入超级块，再分配保存链接信息的那个块。回收时可把一组清单写入新回收块并更新超级块。

分组大小、链尾哨兵和超级块持久化格式依具体文件系统实现而定，不能把教材示例中的固定组大小当作通用常数。
