# Atlas UI 深度优化设计

## 目标

在保留 Atlas 现有信息架构和功能语义的前提下，建立统一的视觉系统与阅读优先交互，重点改善题库、目录、Markdown 阅读、编辑和错误反馈体验。

## 不变的边界

- 保留顶部导航、工作台 / 学习 / 题库 / 设置入口。
- 保留题库左侧目录、右侧题目列表、多题展开、全文搜索和源 Markdown 读写。
- 不改变 Markdown、题库解析、FSRS、搜索和设置数据协议。
- 不引入网络、模型或新的重量级 UI 依赖。
- “今日”不作为 UI 文案或固定日期概念出现。

## 视觉系统

在 `Common.kt` 增加 Atlas UI tokens，统一以下内容：

- 页面背景、面板背景、卡片背景、悬停背景、选中背景、分割线和焦点色。
- 页面标题、区块标题、题目标题、正文、辅助文字、路径文字、按钮文字的字号与行高。
- 小 / 中 / 大圆角、页面边距、卡片间距、区块间距和控件高度。
- 深色 / 浅色主题下的对比度，答案绿色只作为语义色，不铺满大面积高饱和背景。

所有主要页面优先使用 tokens，减少散落的 `sp`、`dp` 和透明度常量。

## 主窗口

`Main.kt` 保持现有导航结构，但调整为稳定的应用壳：

- 顶栏高度固定、导航项以当前页底部指示和轻背景表达选中状态。
- 徽标缩小为辅助信息，不与导航文字争夺层级。
- 设置入口保持齿轮图标，但补充明确的悬停 / 焦点反馈。
- 状态栏降低视觉权重；toast 仅显示短暂反馈，不与主内容抢空间。
- 内容区提供统一内边距和最小可读宽度，避免窗口缩放时内容贴边或过度拉伸。

## 题库阅读页

`LearningView.kt` 拆分为目录树、题库工具栏、题目卡片和题目编辑区域四个职责清晰的组件，但保持当前行为：

- 左侧目录保持递归展开、选中定位和重命名能力，目录文字提升可读性但不放大到挤压正文。
- 右侧工具栏按“搜索 → 范围 → 题库信息 → 次要操作”排列。
- 创建题目、批量创建等低频动作收进次级操作区，避免占据阅读首屏。
- 卡片收起态只呈现题号、标题、来源 / 状态；展开后呈现答案和编辑操作。
- 标题和答案都支持划词复制；拖动选中文本不触发展开、收起或编辑。
- 答案区使用低饱和绿色语义容器，正文颜色、表格、代码块和引用保持统一阅读样式。
- 编辑态在同一张卡片内原地出现，沿用阅读态字号、颜色、边距，只增加光标和轻量焦点提示。
- 自动保存状态显示在编辑区底部，保存失败时保留用户输入并提供重试，不自动关闭编辑界面。
- 前后题导航采用稳定列表快照并防重复点击，列表 key 使用源文件路径与文档偏移，避免重复题号导致崩溃。

## Markdown 阅读

`Common.kt` 的 Markdown 组件统一正文行高、标题层级、列表缩进、引用边界、代码块和表格样式：

- 表格使用一致的表头、行背景和单元格内边距；长表格允许横向阅读，不改变内容。
- 代码块保持等宽字体、语言标识和内边距，避免绿色答案色污染代码内容。
- 正文最大阅读宽度由页面布局控制，超宽窗口不无限拉长行长。

## 弹窗与错误反馈

- 编辑、新建、设置类弹窗使用统一宽度、标题、字段间距和按钮顺序。
- 可恢复错误优先显示为页面内反馈或 toast，不使用难以阅读的系统级 Error 弹窗。
- 所有列表使用稳定且真正唯一的 key；保存重载期间不销毁用户正在编辑的状态。

## 验收标准

- 题库首屏在 1280×820 和较窄窗口下均不出现按钮挤压、文字裁切或异常横向溢出。
- 题目标题、答案、来源路径可划词复制，拖动选择不会触发卡片动作。
- 展开多个题目后仍能独立阅读和编辑，编辑不改变其他卡片状态。
- 编辑时视觉上与阅读态一致，只出现光标 / 焦点提示；自动保存失败不会丢输入。
- 重复题号、保存重载、连续前后导航不崩溃、不自动关闭编辑界面。
- 深色 / 浅色主题和全局字号设置保持可用，Markdown 表格 / 代码块 / 引用视觉一致。
