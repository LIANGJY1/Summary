# 会话知识沉淀与出题

## 核心契约

用户显式调用本 skill，即授权在既有知识库规则与本次输入范围内完成提取、核验、写入、出题和验证。默认一次性交付，不展示候选菜单，也不要求用户承担合并、取舍、命名或排版判断。

**双输入模式**，每次调用由用户指明：

- **会话模式**：以当前会话为输入，以**用户问题边界**控制内容——每个有效用户问题都必须有归宿，助手回答只是待核验素材，不能独立创造知识主题。
- **文章模式**：以文档、网页或粘贴文本为输入，以**材料内容边界**控制内容——覆盖材料的主题、概念、机制、方法与边界。文档必须完整读取；网页先抓取正文及页面标题；无法访问时要求用户提供正文或可访问链接。文章是外部学习材料，**沉淀+出题一体**，落点为学习资料文档（见出题落点）。

完全消化意味着全部用户意图（或材料主线）均被处理、错误和旁支均被主动清除，不意味着把每句话都写入。

**调用即出题**：每次调用为本轮全部落库主题生成复盘题（同源题目），写入知识文档本身；atlas 同源题目机制直接读取知识库文档，无 inbox、无协议块、无同步步骤。

固定知识库为 `/home/liang/Project/MyProject/Summary/knowledge-base/`。保留工作树已有修改，不清理、不回滚、不自动 commit。凭据、token、密码、个人信息、内网地址、私有链接和可重建秘密不得入库。

## 内容边界与 profile

只接收脱离原输入仍成立的声明性知识：事实、机制、坑、适用边界、权衡与可迁移做法。

| 输入 | 归宿 |
|---|---|
| 编程语言语法、类型、标准库、工具链行为 | `language-note`，进入 `language/`（Q&A 即笔记主线） |
| 换项目仍成立、通过复习者测试的机制或经验 | `knowledge-entry`，进入根级大类 |
| 文章/网页/粘贴文本的学习内容 | 并入或新建对应学习资料文档（`android/`、`网络/` 等目录）小节，Q 块跟随小节 |
| 可重复流程、提示词、代理协议 | `session-to-skill` |
| 源码行注释或库级源码讲解 | `source-annotator` |
| 只服务下一次续做的上下文 | 交接文档，不进知识库 |
| 普通"总结一下"，未要求持久化 | 只回复，不写文件 |

不得按输入顺序创建"会话总结.md"或"文章摘抄.md"。先定知识内核和归宿，再按主题归并。

## 出题：同源题目

题目是知识文档内容本身，不是附属元数据。**格式契约**（atlas `SourceQuestions` 直接解析）：

```
**Q<编号>: 题面（完整命题、单行、自包含）？**

面试级答案 prose——先直答，再按因果链展开，含必要边界与最小示例；
答案范围到下一个 Q 标记或下一个标题为止。
```

- 只写粗体标记形态 `**Qn: 题面**`（解析器另认标题/纯文本形态，但不主动使用）；题面不依赖"上文第几节"。
- 编号在文档内全局唯一；追加时从已有最大编号继续，不重排既有编号。
- 覆盖与拆分、面试级答案标准、逐题质量门见 [出题内容规则](references/quiz-content-rules.md)，生成前必须读取，生成后按其逐题验收。
- **落点**：`language-note` → Q&A 就是笔记主线（新增小节即新增 Q）；`knowledge-entry` → Q 块写在条目"启示"段之后（默认落点，用户可调整）；文章模式 → 学习资料文档对应小节之后。
- **题目与正文同址同改**：条目/小节结论收窄或反转时，就地改写其 Q，不追加同义副本；删除条目时同步删除其 Q。
- 题库可见性由 atlas 设置（支持解析的文档/目录）决定，不在本 skill 职责内。

## 一次性流程

### 1. 锁定输入与写入范围

读取完整输入——会话模式列出所有用户提出的问题、补充条件、纠正和明确结论；文章模式列出材料主线、章节结构与候选主题。记录目标文件路径、存在性和内容 hash，并将预计触及的文件设为白名单；工作树中的其他修改不归因于本轮。

**完成判据**：每条用户输入（或材料章节）都被标记为"形成主题""并入相邻主题"或"不是声明性知识"，且每项都有理由；目标文件与初始状态已记录。

### 2. 建立内容边界

会话模式对每个有效用户问题、文章模式对每个候选主题，在内部建立以下记录，不向用户展示：

```text
原始问题/章节：
真正要解决的问题：
必要场景：
核心结论：
必要支撑：
待核验事实：
排除旁支：
与其他问题的关系：
目标文件与动作：
```

相邻追问共享同一概念和复习入口时合并；一个问题包含互不依赖的结论时拆分。会话模式中用户随后追问的旁支升级为用户主题；会话中没有用户来源的主题不进入本轮知识正文。

语言笔记必须读取 [语言笔记提炼规则](references/language-note-extraction.md)，再读取 `language/README.md` 和目标文档；其他 profile 读取目标文档局部契约。

**完成判据**：所有输入单元恰好映射到一个主题或有明确的非知识去向；不存在仅由助手主动扩展产生的主题。

### 3. 核验事实与脱敏

助手回答与会话外的材料陈述统一标记为 `unverified`，只能提供检索线索。优先使用本地代码、可重复命令、语言规范和官方文档确认事实；项目行为不得从方法名、调用形式或常见模式推断。文章内容按"原文事实 / 合理推导 / 无法确认"区分，推导不得写成事实。

内部证据等级：

- `observed`：直接看到的代码、文档或输出。
- `verified`：可重复命令或独立证据交叉确认。
- `external`：官方外部资料，并已核对适用平台与版本。
- `inferred`：有依据但未验证，只能明确限定后保留；会影响正确使用的推断应删除或阻塞。

扫描原会话、文章、示例、补丁和最终 diff 中的敏感信息；需要保留结构时使用 `[已脱敏：类型]`。

**完成判据**：每个准备写入的技术结论都有证据等级；绝对表述有直接依据；项目特定推断和敏感内容已清除。

### 4. 路由、归并与成形（含出题）

依次读取：

1. `knowledge-base/CONTEXT.md`；
2. `knowledge-base/ROUTING.md`；
3. 目标大类规则，或 `language/README.md` 与目标语言文件，或目标学习资料文档。

按知识内核、目标边界和复习入口确定唯一落点。同义命题并入既有内容；两个视角确实独立时分别写并建立链接。示例必须最小、完整、可运行，或明确标出省略与未验证部分。

每个落库主题（新建与就地修订）同步设计复盘题：读取 [出题内容规则](references/quiz-content-rules.md)，按其覆盖、拆分与答案标准成形，落点遵循出题契约。既有题目仍然正确的并入本轮修订，不重复出题。

新建根级大类、改变路由边界、修改 ADR，属于知识体系扩张，不包含在普通沉淀授权中；只有确实需要时才因这一项暂停。既有大类中的新增、合并和修订可直接执行。文章模式不新建大类：材料并入既有学习资料文档，确实没有对应文档时暂停询问用户。

**完成判据**：每个主题只有一个落点；正文遵守目标文档契约；标题、正文和示例均没有越出内容边界；每个落库主题都有题目归宿（出题或明确并入既有题）。

### 5. 安全写入

写入前重新读取白名单目标并比较 hash。无外部变化时使用 `apply_patch` 精确修改；出现并发变化时重新审阅并合并，不能安全合并才暂停。重复执行应得到"无变化"或就地修订，不能追加同义副本。

结论补充或收窄时就地修订，并按出题契约同步改写该条目/小节的 Q。`knowledge-entry` 发生结论反转时遵守目标规则建立 `supersedes`；`language-note` 直接按教学主线改写。同步目录、编号和所有交叉引用。

**完成判据**：只有白名单文件发生预期修改；已有用户改动被保留；同义内容、目录和链接保持一致；题目与正文同步。

### 6. 验证与交付

先逐项执行目标文档的内容验收，再运行结构校验：

```bash
python3 /home/liang/.agents/skills/session-to-knowledge/scripts/check_kb.py <entry 文档...> --profile entry
python3 /home/liang/.agents/skills/session-to-knowledge/scripts/check_kb.py <language 文档...> --profile language
```

校验覆盖 Q 块：编号不重复、题面非空。检查最终 diff，确认每个输入单元都有归宿、每个正文主题能追溯到输入、助手旁支没有变成新主题、题目与落库主题一一对应。校验失败时自行修复；只有安全、路由体系扩张或不可消解冲突才向用户报告阻塞。

最终只报告：写入或修订了什么、出题数量与落点、主动排除了什么、验证结果、仍存在的客观阻塞。没有合格内容时交付 `0 条` 及原因。提醒仓库未自动 commit。

**完成判据**：内容审读和结构校验均通过，最终报告不再要求用户作编辑决策。

## 决策表

| 信号 | 自动动作 |
|---|---|
| 用户直接提问、补充或纠正 | 必须覆盖或明确并入 |
| 用户继续追问助手提到的旁支 | 升级为用户主题 |
| 助手直接回答 | 核验后重写 |
| 文章章节承载材料主线或机制 | 形成主题，沉淀+出题一体 |
| 核心结论所必需的背景 | 压缩为必要支撑 |
| 助手主动扩展且用户未追问 | 排除，不独立成题 |
| 输入中没有出现的新主题 | 排除 |
| 项目行为只有命名或惯例支撑 | 排除推断，只保留可观察语法 |
| 同一命题已存在 | 就地并入 |
| 条目/小节结论修订 | 同步改写其 Q，不追加同义副本 |
| 没有可迁移内容 | 写入 0 条并结束 |

## 停止条件

正常编辑判断由 skill 自主完成。只有以下情况暂停：知识库路径不可用或存在多个候选库；路由无法唯一确定且不同选择会改变知识含义；文章没有合适的学习资料文档归宿；目标在写入期间发生无法安全合并的变化；内容涉及无法安全脱敏的信息；需要新建大类、改变边界或作出难以逆转的 ADR。
