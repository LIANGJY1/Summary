# 题库展开卡右侧空白：把 1040 阅读度量提升为「整卡内容列」并居中

## 背景（为什么是 1040）
- §6.4.8：cap 为修「长答案铺满宽屏、长行难读」——**度量本身是有意设计，不能放宽**（推翻上一版 fillWidth 方案的原因）。
- §6.4.9 / §6.4.10 明文约定：「**题目与答案共享同一内容边缘 / 维持同一左边缘**」。
- 现状实现偏离了约定：cap 只套在答案的 MarkdownText（1040 左对齐），题干仍是全宽、卡面 1240——右侧单侧空 ~140dp，即红框突兀感。

## 新方案（落实约定而非放宽度量）
**`ui/LearningView.kt` 题卡**：Surface 内容外包一层 `Box(fillMaxWidth, contentAlignment = TopCenter)`，把卡内现有的 `Row(fillMaxWidth)`（题干 + 展开区 + 操作行的根）改为 `widthIn(max = ui.readingMaxWidth).fillMaxWidth()`。

效果：
- 题干、答案、操作行共享同一 1040 内容列，左右边缘一致——完整落实 §6.4.9/§6.4.10 的「同一内容边缘」；
- 留白对称分布在两侧，不再是单侧突兀空白；卡面仍全宽（列表视觉连续）；
- 1040 长行度量原样保留（黑曜复核的目的不变），阅读页/预览浮层/闪卡背面零影响；
- `MarkdownText` 一行不改。

只动 `LearningView.kt` 题卡一处包装，其余零改动。

## 验证
gradle test 回归 + 安装后目测：展开卡两侧对称留白、题干与答案左缘对齐。
