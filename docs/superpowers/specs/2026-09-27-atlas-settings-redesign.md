# Atlas 设置中心重构设计

## 目标

把当前纵向堆叠的设置页重构为桌面端双栏设置中心，让高频设置、知识库操作、隐私边界、复习、录屏和关于信息各自拥有清晰的层级，同时保持现有设置字段、持久化协议和默认知识库路径不变。

## 设计决策

- 左侧固定设置导航，右侧只显示当前分区，避免所有内容同时展开。
- 顶部增加当前状态摘要：当前主题、知识库路径、扫描状态；摘要只读，不复制编辑控件。
- 每个分区使用统一的 `SettingsSection` 容器：标题、说明、控件组、操作栏；不再让每个字段都单独套卡片。
- 高频项（外观、知识库）优先；隐私与索引、录屏、复习和关于按导航切换。
- 保存行为保持原有语义：即时保存的控件继续即时保存，文本批量配置继续显式保存；更换知识库和全量重扫保留现有确认/执行逻辑。
- 主题编辑器继续使用现有 `ColorSettingsPage` 和 `ThemeEditDialog`，只统一入口和视觉组件，不改 V2 主题数据格式。
- 不清空、不迁移、不覆盖用户已有设置和知识库路径。

## 视觉结构

- 页面底使用 `Theme.Background`，左侧导航使用 `Theme.Panel`。
- 当前导航项使用轻量 `Theme.Selected` + 强调色文字，不使用大面积彩色填充。
- 右侧内容最大宽度 960dp；摘要使用两到三列信息块，表单使用单列阅读宽度。
- 破坏性或低频操作放到“高级与诊断”分区，并保持错误色只用于删除/错误。

## 范围

- `atlas/app/src/main/kotlin/atlas/ui/SettingsView.kt`
- `atlas/app/src/main/kotlin/atlas/ui/ColorSettingsView.kt`
- `atlas/app/src/main/kotlin/atlas/Main.kt`（仅在需要时调整设置页面容器）
- `atlas/PRD.md` 记录信息架构和视觉决策

不改变 `SettingsStore`、`AppStore`、主题 V2 编解码和知识库索引协议。
