## 4. 结论

1. evdev 层对事件流的三种加工（复制、packet 判定、溢出覆盖）全部以行号落地；除溢出外无丢弃、无合并、无延迟、无改写——B9/B10/B25。
2. eventTime 的最终裁决（兑现批01 遗留）：ktime_get()＝CLOCK_MONOTONIC（B16），取时点＝evdev_events :300 每次 flush 一次（B17），两个消费者 client 都设 MONO（B18），同源机制成立（B19）。
3. 数据面：touch.txt 无 SYN_DROPPED 双判据（B23）→ getevent client 未溢出 → 1194 间隔统计在"evdev 不丢帧"前提下透传成立；EventHub client 侧未证（B24）。
4. trace 相对时间 00:00:06.787410 与 CSV/契约数值交叉命中；CSV 的 assuming_clock 假设口径被单点吻合约束（B22）。
