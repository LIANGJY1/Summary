## 4. 结论

1. 主线闭环完成：input_event(:438)→input_handle_event(:367)→input_get_disposition(:261)→vals 攒批(:386-400)→FLUSH(:402-405)→input_pass_values(:128)→input_to_handler(:93)→handler->events(:114-115)→evdev 端点（引用级）。
2. 硬结论：input core 事件路径无队列、无定时器、无可睡眠点（B30）；autorepeat 定时器只作用于 EV_KEY 且本设备未武装（B20/B28）；间隔分布在 core 入口与出口之间无改变机制（B31）。批01 A19 的 input core 段升级为已证，evdev 段留 03。
3. 机制四问齐答（问一攒批、问二 repeat 定时器、问三 14 步调用链、问四 input_filter），每问按"规则/谁设置/谁执行/后果"展开。
4. 本流量化：max_vals=80（估计 78+2）；packet 构成 1153×2＋41×1＋1×4；强制 flush（阈值 78）与孤立 SYN 丢弃均未触发。
5. trace 配对：完成点链条已证；契约 :76 数值逐字引用；为 03（evdev_events 入口）/04（读端）划界。
