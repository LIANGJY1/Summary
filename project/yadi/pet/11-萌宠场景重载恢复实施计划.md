# 萌宠场景重载恢复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Kanzi 场景重载和实时形象切换后恢复萌宠的有效节日皮肤、显隐状态和当前动作。

**Architecture:** 首次 `KanziReady` 继续处理冷启动补发，后续就绪沿进入统一场景恢复路径。实时形象切换另走动态预制体恢复：等待创建后恢复 `festivalSkin`，对当前持续动作写结束码并隔帧写开始码；期间如收到全局就绪沿，则提前进入恢复且不重复下发形象。恢复从 `festivalSkin` 与 `currentAction` 读取现状，动作不重新竞合；皮肤恢复不重复触发推荐状态回报或节日音效。

**Tech Stack:** Kotlin, Android Handler, PetStateMachine scenario harness.

**Spec:** [10-萌宠场景重载恢复设计.md](./10-萌宠场景重载恢复设计.md)

## Global Constraints

- 恢复下发顺序为形象/皮肤、显隐、动作。
- 不改变首次 Kanzi 就绪的出场语义。
- 恢复动作保持 `currentAction` 原值，不重新执行竞合裁决。
- 场景恢复不刷新节日皮肤时限，也不重放节日音效或重复回报。
