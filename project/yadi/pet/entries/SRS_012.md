# SRS_012 — 节日惊喜皮肤

> ✅ 已定 2026-08-27
> 本文件是本条目事实／问答／开放点的唯一权威。全局决策／规则／术语／信号清单见 [01-需求与决策](../01-需求与决策.md)；竞合规则见 [02-音效动作冲突矩阵](../02-音效动作冲突矩阵.md)；不确定点的代码落点见 [04-代码方案](../04-代码方案.md) §6 收敛表。

## 事实

- 前置：当前日期为节日、萌宠前台显示；输入＝节日信号
- 节日范围：春节、元旦、端午、中秋、国庆
- 皮肤由 Kanzi 执行并反馈，服务接反馈后同步播放节日音效；皮肤与任意动作“同时”叠加、不参与排队；音效每上电至多一次
- 音效竞合：与其他功能音效→遵循音频整体策略；与萌宠动作音效→随动作竞合保持一致；与生日音效→按《智能推荐_SRS》优先级；异常策略参考《智能推荐_SRS》
- 原文 ID 双下划线，按 012 登记；输入/描述两处勘误已确认更正

## 对外接口与交付约束

- 节日信号由智能推荐侧判定，经 `LauncherLib` 的 pet 客户端发往全局 `LauncherService`；结果由同一客户端回调给智能推荐侧（D006）。
- SDK 管理连接与重连；跨天或重连时重推当前节日状态，Launcher 侧按同值幂等规则处理。底层节日码、回传状态与对账规则见 [06-智能推荐接口设计](../06-智能推荐接口设计.md)。
