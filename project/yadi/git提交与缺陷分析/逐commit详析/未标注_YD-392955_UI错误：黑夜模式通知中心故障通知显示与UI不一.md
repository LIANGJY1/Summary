# YD-392955 · 黑夜模式通知中心故障通知分隔线显示异常
- **提交**：`177948c1` | 2026-07-30 | liujinfeng | SystemUI | bugfix
- **缺陷库**：未关联单号（缺陷库 defs 为空）

## 问题
黑夜模式下通知中心的故障（分组）通知卡片内出现多余分隔线，与 UI 稿不一致。

## 根因分析
分组通知模板 `group_notification_template.xml` 在 `group_header` 与 `notification_list` 之间、`notification_list` 与 `expansion_footer_holder` 之间各画了一条分隔线（`header_divider`、`footer_divider`，背景 `@color/notification_list_divider_color`）。该分隔线颜色在黑夜模式下的观感与设计不符（设计稿要求分组卡片内部不画线）。同时 `GroupNotificationViewHolder.java` 在 `bindExpandedGroup()`/`bindCollapsedGroup()` 里手动 `setVisibility` 切换 `mHeaderDividerView`，布局与代码双向耦合，纯属多余的视觉元素。

## 关键代码修改
改动文件：`application/SystemUI/src/main/java/com/android/systemui/notification/template/GroupNotificationViewHolder.java`、`application/SystemUI/src/main/res/layout/group_notification_template.xml`
```diff
--- application/SystemUI/.../template/GroupNotificationViewHolder.java
-    private final View mHeaderDividerView;
...
-        mHeaderDividerView = view.findViewById(R.id.header_divider);
...
     private void bindExpandedGroup() {
-        mHeaderDividerView.setVisibility(View.VISIBLE);
--- application/SystemUI/.../res/layout/group_notification_template.xml
-            <View
-                android:id="@+id/header_divider" ... android:background="@color/notification_list_divider_color" />
-            <View
-                android:id="@+id/footer_divider" ... android:background="@color/notification_list_divider_color" />
             <ImageView
                 android:id="@+id/notification_list"
-                android:layout_below="@id/header_divider"
+                android:layout_below="@id/group_header"
             <FrameLayout
                 android:id="@+id/expansion_footer_holder"
-                android:layout_below="@id/footer_divider">
+                android:layout_below="@id/notification_list">
```

## 为什么能修复
直接删除两个分隔线 View 并把依赖其定位的 `notification_list`、`expansion_footer_holder` 的 `layout_below` 重新锚定到 `group_header`/`notification_list`，相对布局链保持完整；ViewHolder 中对应的 findViewById 与 setVisibility 调用一并移除，编译与运行时引用一致，多余线条消失。改动干净，无明显副作用。

## 复盘与经验
- UI 稿评审要在模板层面确认分隔线归属：列表分隔线应由列表容器/ItemDecoration 统一绘制，塞进单个通知模板里会在昼夜两套主题下各自出错。
- 删除被 `RelativeLayout` 依赖锚定的 View 时，必须同步改所有 `layout_below/layout_above` 引用，否则布局链断裂。
- 布局元素与 ViewHolder 的 findViewById 成对存在，删 UI 要同步删代码引用，否则运行期 NPE（本提交两处同步干净）。
