## 复盘与要点
- `.gradle/`、`.idea/` 等本机状态目录不应入库；下一笔提交（a1dfb97d）立即补 .gitignore 并删除这些文件，说明首提交前没有做 .gitignore 检查。
- 教训：新仓库第一笔提交前先落 .gitignore；大二进制一旦入库就永久占用仓库体积（即使后续删除，历史仍在）。
