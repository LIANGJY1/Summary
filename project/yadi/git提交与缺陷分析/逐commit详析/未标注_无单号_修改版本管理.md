## 需求/目标
清理历史上误提交进版本库的 Gradle 构建产物（`.gradle/` 缓存与 version catalog 生成的 `.class` 文件），并把 `/.gradle/` 加入 `.gitignore` 防止再次误提交。

## 复盘与要点
- IDE/构建工具缓存目录（`.gradle/`、`.idea/`、`.cxx/`）应在仓库初始化时一次性配全 ignore，否则二进制膨胀历史无法靠后续删除挽回（大文件会永久留在 pack 里）。
- `local.properties`（含本机 SDK 路径）本就不该入库，此次一并移除，克隆环境差异问题会显著减少。
