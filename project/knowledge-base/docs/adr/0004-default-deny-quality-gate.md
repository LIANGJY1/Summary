# 知识沉淀采用 default-deny 质量门，单次 ≤ 3 条

首次试运行（android-ui.md）在流程完整执行（要主旨、出清单、用户勾选都走了）的情况下仍产出 8 条低价值条目：行业常识（View 背景不响应 padding）与本次任务的操作结论（差异三分类决定收编路径）被当作"经验"写入，且条目满是会话专名、六个月后无法冷读。原因：质量门槛是软指导，由刚干完长活的 agent 自评，必然宁滥勿缺；用户面对 8 条清单也无逐条甄别的力气。决定改为 default-deny：每条候选必须通过复习者测试（写出六个月后遇到什么问题会翻到它、翻到后能直接用），显式排除常识与任务操作结论，单次沉淀 ≤ 3 条且允许 0 条，skill 内置真实事故的好/坏对照样本校准判断。

## Consequences

- 召回率有意压低：真有价值但说不清复习场景的细节会被拒——接受，知识库的价值在"条条可复习"，不在"什么都在"。
- 条目不再带状态/来源元数据行（用户裁定：为复习可读性服务，验证信息融进"现象与依据"正文）。
