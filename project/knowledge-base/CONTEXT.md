# 会话知识沉淀（knowledge-base）

把 agent 会话中产生的经验固化为可累积、可检索的知识文档的体系。知识库固定位于 `Summary/project/knowledge-base/`。

## Language

**知识库 (knowledge-base)**:
会话经验的唯一沉淀地：`Summary/project/knowledge-base/` 下按大类组织的一组知识文档。
_Avoid_: 笔记库（指整个 Summary 仓库）、文档目录

**大类**:
知识库下的一个 Markdown 文档，收纳同一主题的全部条目（如 `sdk-design.md`）。文件名英文 kebab-case，文档标题用中文。
_Avoid_: 分类、知识文档、目录（与文件系统目录混淆）

**条目**:
大类文档内的一个 `## 节`，一条独立成立的知识；同名条目并入既有条目，绝不重复开节。
_Avoid_: 知识点、段落

**边界**:
每个大类文档顶部的"收什么 / 不收什么 / 与兄弟文档如何分工"声明；新建大类必须先立边界。
_Avoid_: 说明、前言

**沉淀**:
把当前会话中非显而易见、脱离本会话语境仍成立的结论写入知识库的行为；流水账与过程记录不属于沉淀。
_Avoid_: 总结（泛指）、归档

**修订注记**:
条目末尾"（YYYY-MM-DD 修订：……）"一行，记录就地修订的来历；结论反转不用它，改用 supersedes。
_Avoid_: 变更日志、日期戳

**supersedes**:
条目间的替代标记：结论反转时新开条目声明 supersedes 旧条目，旧条目名后注明被替代；旧条目正文不删。
_Avoid_: 作废、删除

**知识**:
可迁移的结论：换一个项目仍然成立，且能通过复习者测试（六个月后遇到什么问题会翻到它、翻到后能直接用）。
_Avoid_: 经验（泛指）、结论

**工作记录**:
只对本次任务/项目有意义的操作结论（怎么收编、怎么分工、改了什么）；不属于沉淀，归宿是项目文档或交接。
_Avoid_: 知识、踩坑总结

**技能沉淀**:
可复用的工作流程固化为 `SKILL.md`（由 session-to-skill 负责），不进知识库。
_Avoid_: 与"沉淀"混用

**交接**:
给下一个 agent 续做用的上下文文档（由 handoff 负责），不进知识库。
_Avoid_: 与"沉淀"混用
