## 第11章 Android 架构

**Q1: Android KTX 是什么？**

**Android Kotlin Extensions**：AndroidX 旗下的一组 ktx 库（`androidx.core:core-ktx`、`fragment-ktx`、`lifecycle-ktx` 等），给 Android 框架的 Java API **外挂一层扩展函数/扩展属性**，把 Java 风格的啰嗦调用变成 Kotlin 惯用风格——不提供新能力，纯语法糖层：

```kotlin
// Java 风格
val editor = sp.edit()
editor.putInt(KEY, v)
editor.apply()

// KTX：一行（就是 01 笔记 Q1 那个扩展函数）
sp.edit { putInt(KEY, v) }

// 其他常见例子
"content://xxx".toUri()      // 替代 Uri.parse(...)
bundleOf("key" to 1)         // 替代手写 Bundle
lifecycleScope.launch { }    // lifecycle-ktx：给 LifecycleOwner 挂协程作用域
```

Java 调用方不受影响——KTX 只是 Kotlin 侧的扩展函数，底层仍走原框架 API。
