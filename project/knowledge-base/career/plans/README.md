# Career Plans

计划统一放在本目录，按"总路线 → 周计划 → 周复盘"三层管理：

- `roadmaps/`：总路线、阶段 Gate、优先级与时间基线（当前 [01-six-month-roadmap.md](./roadmaps/01-six-month-roadmap.md)）。
- `weekly/`：每周唯一执行清单（当前 [2026-W38.md](./weekly/2026-W38.md)）。
- `reviews/`：周末复盘（当前 [2026-W38.md](./reviews/2026-W38.md)）。

## 规则

- 总路线只定方向、优先级、Gate 和周主题；周计划只写本周做什么、做到什么算完成、依赖哪些资料；复盘只记实际完成、数据、问题、调整。
- 文件名用 ISO 周次（如 `2026-W38.md`），文件首行注明对应计划周次（如 W0）；计划与复盘同名配对。
- 计划必须可执行、可勾选；不复制总路线全文，不在计划里记复盘结论。
- 复盘最多确定下周三件事；不把未完成事项堆成新的长期清单。
- 通用知识查本目录父级 knowledge-base；周计划只安排阅读、源码、实践、输出和复习动作。
